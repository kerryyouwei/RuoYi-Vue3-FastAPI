# 股票池筛选 + 回测：详细执行思路

> 适用对象：固定股票池（几十支 A 股）
> 原则：先证明“信号有没有 edge”，再证明“组合能不能稳定”，最后才谈仓位和资金管理。

---

## 0. 总体流程图

```text
数据层(点时数据/可行性标记)
        ↓
函数层(买点/卖点/过滤/风控 积木化)
        ↓
第一轮:裸信号广筛(固定仓位+固定出场)
        ↓
第二轮:买点+卖点+过滤组合(walk-forward)
        ↓
第三轮:执行层重放(事件驱动+成交约束)
        ↓
统计确认(多假设校正/状态分组/跨周期)
        ↓
仓位与组合层
```

---

## 1. 输入定义

### 1.1 股票池

- 几十支 A 股，建议显式配置为静态列表 `stock_pool.csv`。
- 每支股票记录：
  - `code`：交易所代码
  - `name`：名称
  - `list_date`：上市日期
  - `delist_date`：退市日期(如果有)
  - `is_st_history`：历史上是否曾为 ST/退市整理期
  - `industry`：行业
  - `备注`：是否新股、是否低流动性等

### 1.2 研究区间

建议：

```text
训练区间: 2019-01-01 ~ 2022-12-31
样本外:  2023-01-01 ~ 2025-12-31
滚动验证: 按年滚动 walk-forward
```

至少需要 5 年以上日线数据，否则交易次数不足以做统计判断。

### 1.3 数据字段

日线级别建议准备：

| 字段 | 用途 |
| --- | --- |
| date | 交易日 |
| open/high/low/close | 价格 |
| volume / amount | 流动性与成交量约束 |
| adj_factor | 复权因子 |
| ex_date / dividend / split | 分红送配事件 |
| suspend_flag | 停牌标记 |
| limit_up_price / limit_down_price | 当日涨跌停价 |
| is_st | 当日是否 ST |
| turnover_rate | 换手率 |
| free_float_mv | 流通市值 |

## 2. 数据层硬约束

这一层不做任何策略判断，只负责保证“数据没有偷看未来”。

### 2.1 点时规则

1. 任意 K 线 `t` 上，函数只能使用 `<= t` 的数据。
2. 成交发生在 `t+1`：
   - 可用价：`t+1` 开盘价；
   - 若 `t+1` 开盘涨停且为买入，视为无法成交；
   - 若 `t+1` 开盘跌停且为卖出，视为无法成交；
   - 视为无法成交时按策略规则顺延或放弃，不允许默认“一定成交”。

### 2.2 复权规则

研究信号建议统一使用**后复权价格**，原因：

- 后复权价格从历史向未来拼接，不存在前视偏差；
- 与实盘价格差异由复权因子单独记录。

资金曲线计算时用**真实价格 + 事件调整**，避免分红送配产生虚假收益或虚假亏损。

### 2.3 可交易性标记

每天每支股票生成布尔标记：

```text
tradable = not suspend and not st and not 上市不足N天 and volume > 最小流动性门槛
```

信号可以触发，但**成交必须要求 tradable 为 true**。

### 2.4 幸存者偏差

- 股票池如果是在今天选出来的，就天然存在幸存者偏差。
- 缓解方式：
  - 记录选股依据；
  - 尽量包含历史上已退市的成分；
  - 汇报股票池构建日期与构建规则；
  - 对比“原始池 vs 剔除后来表现最好的股票池”的稳健性差异。

## 3. 函数层设计

所有函数统一为纯函数：

```text
输入: 截至当前K线的数据窗口 + 参数
输出: 明确动作
```

### 3.1 函数类型

| 类型 | 输出 |
| --- | --- |
| 买入信号 | long / none |
| 卖出信号 | close_long / none |
| 过滤器 | allow / block |
| 止损止盈 | close_long / none |
| 时间出场 | close_long / none |
| 仓位函数 | 目标仓位 |

### 3.2 函数元数据

每个函数必须带：

```yaml
name: breakout_20d
type: entry
version: 1.2.0
params:
  lookback: 20
min_bars: 20
period: daily
universe_hint: a_share
golden_tests:
  - 已知趋势样本
  - 边界样本
  - 数据不足样本
```

### 3.3 黄金测试集

每个函数上线前必须通过 3 类测试：

1. **常规样本**：人工确认的典型买/卖点。
2. **边界样本**：数据不足、连续涨停、停牌复牌、除权日。
3. **未来数据探针**：故意修改未来 K 线，输出必须不变。

## 4. 第一轮：裸信号广筛

目标不是找“赚钱组合”，而是判断**单块函数本身有没有统计 edge**。

### 4.1 固定试验条件

为避免多因素污染：

- 固定仓位：每次开仓 1 单位名义价值，例如 10% 总资金或固定 1 万元。
- 固定基础出场：例如统一 10 个交易日后收盘平仓，或统一 10 日低点平仓。
- 固定成本：默认佣金万 2.5，卖出印花税千 0.5，滑点 0.1%。
- 每天最多同时持有 5 支。
- 只做多，不做空。

### 4.2 评估方法

对每个买入函数：

1. 每次触发买入后，固定持有 N 天。
2. 记录每笔交易：
   - 信号日、成交日、成交价
   - 持有 1/3/5/10/20 天后的收益
   - 是否可成交
   - 当时市场状态
3. 输出指标：

| 指标 | 目的 |
| --- | --- |
| 交易次数 | 判断样本量 |
| 胜率 | 基础质量 |
| 平均收益 | 期望 |
| 收益中位数 | 防止被极端值带偏 |
| 盈亏比 | 结构 |
| 持有期收益分布分位数 | 稳定性 |
| 按年份分组收益 | 时间稳定性 |
| 按股票分组收益 | 跨标的稳定性 |
| 多空基准超额 | 排除市场本身涨跌 |

### 4.3 淘汰线(初始建议值)

不满足以下条件直接淘汰：

- 样本外交易次数 < 30 笔；
- 按年份分组时，超过一半年份期望为负；
- 在超过 60% 的股票上期望为负；
- 扣除成本后期望 <= 0；
- 收益严重依赖少数几笔极端交易(前 5 笔贡献占总利润 80% 以上)。

### 4.4 卖出函数评估

固定统一买点(例如 20 日突破)，然后逐个替换卖出函数，比较：

- 相对“固定 10 日持有”的边际提升；
- 平均持有时间变化；
- 回撤改善；
- 是否导致交易次数骤减。

## 5. 第二轮：组合回测

只用第一轮留下的函数。

### 5.1 组合方式

```text
最终信号 = 买入函数 AND 过滤器 AND 可交易
出场 = 卖出函数 OR 止损 OR 时间出场
```

限制组合数量：

- 第一轮留下的买点 <= 10 个
- 过滤器 <= 5 个
- 出场 <= 5 个
- 优先做有经济含义的组合，不做全排列暴力搜索。

### 5.2 滚动验证 walk-forward

示例：

```text
窗口1: 训练 2019-2020, 验证 2021
窗口2: 训练 2020-2021, 验证 2022
窗口3: 训练 2021-2022, 验证 2023
窗口4: 训练 2022-2023, 验证 2024
窗口5: 训练 2023-2024, 验证 2025
```

每个窗口：

1. 在训练段选择参数；
2. 参数冻结后在验证段运行；
3. 只记录验证段结果；
4. 拼接所有验证段形成最终样本外曲线。

### 5.3 参数平台

对每个候选组合：

- 每个关键参数向上下各偏移 1~2 档；
- 要求邻域内指标不发生方向性崩塌；
- 删除“只有单个参数点好看”的组合。

---

## 6. 第三轮：执行层重放

第二轮幸存者必须用事件驱动引擎重放。

### 6.1 执行规则

- 信号当日收盘生成，次日执行。
- 买入：次日开盘，若涨停不可成交。
- 卖出：次日开盘，若跌停不可成交。
- 停牌：不可成交，持仓顺延。
- 成交量约束：单笔买入金额 <= 当日 amount 的 1%(几十支中小票建议更保守)。
- T+1：当日买入当日不可卖出。
- 现金不足则降低数量，不允许负现金。

### 6.2 成本压力测试

通过后才进入下一步，使用三组成本：

```text
基准: 佣金万2.5 + 印花税千0.5 + 滑点0.1%
压力1: 滑点 0.3%
压力2: 滑点 0.5%
压力3: 手续费和滑点同时加倍
```

若压力测试下样本外期望明显转负，视为成本敏感策略，降级处理。

## 7. 统计确认

### 7.1 多假设校正

记录所有尝试过的组合总数 K。样本外 Sharpe 显著性要考虑 K：

- 简单做法：Bonferroni 或 Benjamini-Hochberg 校验；
- 进阶做法：Deflated Sharpe Ratio。

### 7.2 状态分组

把验证段按以下维度分组，要求没有单一状态依赖：

| 维度 | 分组 |
| --- | --- |
| 年份 | 2023 / 2024 / 2025 |
| 市场状态 | 上证指数 60 日均线上下 |
| 波动状态 | 池内平均 ATR 高低 |
| 个股状态 | 高换手/低换手 |

### 7.3 一致性检验

最终策略最好满足：

- 在 >= 70% 的年份收益为正或回撤可控；
- 在 >= 60% 的股票上可执行且不亏损；
- 收益不依赖单一股票或单一个月。

---

## 8. 仓位与组合层

最后才做，不影响前面的信号判断。

### 8.1 仓位函数候选

- 等权固定仓位(默认基准)
- ATR 逆波动率仓位
- 单票最大权重限制
- 总持仓上限
- 连续亏损降仓

### 8.2 组合规则

- 同时持仓 3~10 支；
- 单票 <= 20%；
- 行业敞口上限；
- 总回撤阈值触发降仓；
- 每日新增开仓上限。

### 8.3 评估

除收益回撤外，额外看：

- 实盘可承受最大回撤时长；
- 月度胜率；
- 换手率和成本占比；
- 收益是否集中在极少数月份。

## 10. 分阶段验收标准

| 阶段 | 通过标准 |
| --- | --- |
| 数据层 | 未来数据探针通过；可交易标记正确率 100% |
| 第一轮 | 每个留下来的信号满足样本量、跨年份、跨股票稳定性 |
| 第二轮 | 样本外曲线来自参数冻结后的 walk-forward 拼接 |
| 第三轮 | 事件驱动重放结果与第二轮方向一致，成本压力下不失效 |
| 统计确认 | 考虑尝试次数后仍显著；无单一状态依赖 |
| 仓位层 | 在真实资金约束下可执行，回撤可承受 |

## 11. 常见坑位清单

1. 用今天还存在的股票构建历史池。
2. 前复权价格直接算历史信号。
3. 涨停日允许买入、跌停日允许卖出。
4. 停牌时用收盘价虚拟成交。
5. 信号和风控混在一起测，看不出收益来源。
6. 只看总 Sharpe，不看分年份、分股票。
7. 参数只测一个点，没有邻域平台验证。
8. 广筛几十上百个组合后，直接挑样本外第一名。
9. 用小市值股的回测结果外推到实盘大资金。
10. 没记录数据版本，三个月后无法复现。
