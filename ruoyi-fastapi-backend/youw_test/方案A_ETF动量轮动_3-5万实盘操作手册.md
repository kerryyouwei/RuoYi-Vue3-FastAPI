# 方案A：行业ETF动量轮动 · 3–5 万实盘操作手册

> 内核来源：`new_strategy.py`（聚宽 V7.5 / V7.32 / V7.43g8 系列）
> 精简落地：把「风格择时 + 行业20日动量 + 弱市避险 + 双创ETF增强」全部用**场内ETF**实现。
> 目的：3–5 万小资金可执行的周频操作，免个股板块权限、免印花税、规避涨跌停买不进与退市黑天鹅。

---

## 0. 先读：重要声明

1. 本手册是策略思路的**工程化落地**，不是收益承诺，也不是投资建议。
2. **回测 ≠ 实盘**。历史表现不代表未来，原策略存在明显的样本内反复调参痕迹，请降低预期。
3. 只投入「亏完也不影响正常生活」的钱；3–5 万若为大部分积蓄，不适合满仓执行。
4. 建议流程：**先模拟盘/小仓跑 1–2 个月 → 验证自己能执行纪律 → 再按计划逐步上仓位**。

## 3. 核心指标怎么算（手算 / 行情软件都有）

### 3.1 沪深300 的 MA20 与 MA60
- 打开行情软件「沪深300指数」（代码 000300），切换到日线。
- 直接看均线 MA20、MA60（几乎所有软件默认显示）。
- 判断结果记三个事实：**今日收盘、MA20、MA60**。

### 3.2 ET F 的「20 日涨幅」
- 方法一（软件）：在行情软件选「区间涨跌幅」，起止日期选「20 个交易日前」到今天。
- 方法二（手算）：
  ```
  20日涨幅 = 最新收盘价 ÷ 20个交易日前收盘价 − 1
  ```
  例：最新 1.10，20 日前 1.00 → 10%。

### 3.3 「超额涨幅」（双创增强用，可选）
```
创业板ETF 相对沪深300 的超额 = 创业板ETF的20日涨幅 − 沪深300的20日涨幅
科创50ETF 相对沪深300 的超额 = 科创50ETF的20日涨幅 − 沪深300的20日涨幅
```

## 4. 六条铁律（照做，不要临时发挥）

### 铁律①：大市择时（每周日做一次）
```
看沪深300（000300）日线：
若  收盘 < MA20  且  MA20 < MA60
  → 判定为「弱市」：
      仓位降到 0~1 成（清仓股票ETF，可留黄金ETF 518880 / 国债ETF / 货基）
      → 本周收工，不再选基
否则
  → 正常市：继续铁律②
```
> 对应原策略 `regime_guard` 与 `foreign` 弱市避险的「柔和大盘保护」思想：
> 只有 **收盘破 MA20 且 均线空头排列** 才认弱市，避免单日波动误杀。

### 铁律②：动量选基（每周日做一次）
```
1. 对标的池里每只 ETF 算「20日涨幅」并排序
2. 取 top 3
3. 3 只等权买入（3万每只≈9500，5万每只≈15800）
```
> 对应原策略 `get_hot_industries`（20 日动量）+ `momentum_rank` 的内核。

### 铁律③：换仓门槛（降频防磨损）
```
只有当  第一名 ETF 的 20 日涨幅 > 5%
  且    第一名已经「换人」（与上次目标不同）
才把持仓换成新的 top3；否则本周不动。
```
- 简单版：**每月第一个交易周才检查换仓**，其余每周只检查「要不要止损/避弱市」。
- 目的：对应原策略 `weekly_rotate`（top1 涨幅 > 5% 且持仓不在其中才换仓，避免每月全换的摩擦成本）。

### 铁律④：双创增强（可选，不贪不亏）
```
若「创业板ETF 或 科创50ETF 相对沪深300 的超额 ≥ 6%」
  → 把其中 1 席强制留给超额更大的那只
否则 → 不单独设置，让动量榜自然选出
```
- 3–5 万**不建议加第 4 席**，只在原来的 3 席里做替换。
- 对应原策略 `ge_etf_signal` / `cyb_signal`（V7.43g8 的 6% 严格阈值）。

### 铁律⑤：止损与冷却
```
每一只持仓，自「买入价」起：
  跌幅 ≥ 8%  → 无条件卖出（激进取 10%）
卖出后：该方向(同一板块) 20 个交易日内不再买回
```
- 用「买入均价」记在记录表里，每天收盘瞄一眼即可。
- 对应原策略 `stop_loss` 的 ETF -10% 止损 + `ETF_COOLDOWN_DAYS` 冷却思想：
  防止「刚止损又追反弹」的循环磨损。

### 铁律⑥：仓位分档与资金纪律
```
正常市：3 只 ETF 满仓（每只 1/3）
弱市：0~1 成（黄金/国债/货基）
任何单只 ETF 不加杠杆、不融资。
后备资金：若中途亏损到本金 70%（回撤 -30%），
   → 停止执行，先复盘 2 周再决定是否继续。
```

## 6. 每日快速检查卡（约 2 分钟，收盘后瞄一眼）

```
□ 有没有任何一只 ETF 距买入价 ≤ -8%？ → 有就卖
□ 有没有触发弱市（收盘破MA20且MA20<MA60）？ → 有就降仓位到 0~1 成
□ 其余不动，不要盯盘、不要盘中止损（按收盘信号执行）
```

> 纪律要点：**只在收盘后看信号，不在盘中追涨杀跌。** 高频情绪操作会把策略收益变成负的。

## 8. 常见坑与注意事项

1. **权限确认**：ETF 一般不需要创业板/科创板权限，但**开户券商政策不同**，先问清能否买 159915、588000。
2. **佣金确认**：找券商确认 ETF 是否「免 5 元最低佣金」，否则 3 万账号 5 元最低收费会明显吃掉收益。
3. **折溢价**：买入前看盘中「溢价率」，> 1% 的高溢价 ETF 当天不追，等回落或换下一只。
4. **分红/拆分**：ETF 分红或份额折算会改变价格，导致「20 日涨幅」「止损线」失真。用**复权价**（前复权）计算更稳。
5. **流动性**：只交易日均成交额达标、买卖盘口厚的品种；小成交清淡的 ETF 有冲击成本。
6. **非同步调仓**：先卖后买，避免「先买却卖不出」的资金纠纷；卖出的钱到账（T+1 可用）后再买。
7. **情绪管理**：单周被套、连续止损时最容易放弃纪律；先降仓、再复盘，不赌气加仓。
8. **不要抄底补仓**：本策略是「做强势、止损弱」，弱市下不逆势摊低，拿着货基等待信号即可。
